# ⚡ Plataforma de Monitoreo de Infraestructura Eléctrica y Prevención de Apagones (CFE / CDMX)

![Imagen : CFE y sus apagones ](https://github.com/arianaSilva-dev/proyectoModeloEntidadRelacion/blob/CFE_img/apagonCFE.jpeg)

## Descripción del Problema.

En zonas urbanas densas como la CDMX, las fallas en el suministro eléctrico (apagones) provocadas por sobrecargas en transformadores o factores externos afectan de manera constante a la ciudadanía como transformadores viejos o sin mantenimiento. El reto operativo para la Comisión Federal de Electricidad (CFE) radica en vincular eficientemente el reporte ciudadano con el equipo físico afectado (el transformador o circuito), priorizar la atención bajo métricas de tiempo de respuesta (SLA) y mantener un registro histórico para la prevención de fallas recurrentes.

Este proyecto implementa un modelo de datos con el fin de automatizar y dar solución a dicha problemática.
